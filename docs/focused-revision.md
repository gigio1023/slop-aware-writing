# Focused revision boundary

The September 2026 composition change gives general document authoring and production to `technical-report-writing` in [agent-skills](https://github.com/gigio1023/agent-skills). `share-internal-doc` in Gigio Pack remains the full entry for colleague-facing documents and authorized sharing. This repository keeps two independent skills: explicit slop revision and Korean semantic clarity.

The removed authoring reference is preserved in Git history. Its selected general writing guidance was adapted into the writer with source and license attribution. There is no automatic second pass, shared global writing policy, or requirement to install another package to revise a draft here.

The Korean pattern changes are contextual editorial rules based on direct user feedback and meaning preservation, not new empirical AI-authorship findings. Existing source evidence stays identified. Repeated endings, contrast structures, connectors, and paragraph lengths are inspected for an actual reader problem rather than changed at a numeric threshold.

Existing installations keep the same names and repository. A separately requested refresh updates them; publishing a PR does not install anything. Review any local standing instruction that still invokes slop for all new writing during an explicitly requested configuration update.

Validation includes package discovery, metadata and resource checks, and static review of expected scenarios. It does not establish new model behavior or representative-reader performance.
